## v0.3.0（2026-10-25）

第二批功能全部完成，界面已在真实软件里逐项点过（对着本机假邮件服务器），引擎测试 17 项全过。

- **邮件会话**：同一话题的往来邮件（包括自己的回复）在列表里合并成一行，带邮件数；打开后按时间上下排列，旧邮件折叠成一行，点开再看；超过 4 封时中间的收成“还有 N 封较早的邮件”。每封都能单独回复、转发、翻译。设置 → 外观 →“按会话分组”可以关。从 v0.2.0 升级上来会自动打开一次。
- **收信规则**：设置 → 收信规则，或邮件右键 →“自动处理此发件人的邮件…”。条件：发件人 / 收件人 / 主题 + 包含 / 不包含 / 等于 / 开头是 / 结尾是；动作：标为已读、加星标、不弹通知、移到归档 / 垃圾邮件 / 已删除。可以“保存并处理现有邮件”。
- **定时发送**：写信窗口“发送”旁的日历时钟按钮；侧栏“定时发送”里可以立即发送、修改（取消定时后回到写信窗口）或取消。软件开着（托盘里也行）才能按时发出。
- **稍后提醒**：阅读区工具栏多了闹钟按钮，快捷键 `H`。
- 列表标题译文去掉了“回复：回复：”这类前缀。

## 安卓版（进行中）

**方案调整（2026-10-25）**：原计划用 nodejs-mobile 在手机上运行 `src/core` 引擎，但它最新只到 Node 18（2024 年后未更新），而 imapflow / nodemailer / mailparser 都要求 Node ≥ 20，`node:sqlite` 要求 ≥ 22.5，走不通。
新方案：界面照样复用（Capacitor 承载），收发信引擎用 Kotlin 重写（Jakarta Mail + SQLite），以 Capacitor 插件的形式实现和 `src/shared/api.ts` 一样的 `MailApi` 接口；后台收信交给安卓的前台服务 / WorkManager。

分四步：
1. ✅ 开发环境 + Capacitor 工程，界面配演示数据在手机上跑起来（2026-10-25，一加手机实测：状态栏/手势条避让、阅读页、返回键都正常；截图见 `docs/android-list.png`、`docs/android-reader.png`）。
   演示版 APK：`dist/MoyerMail-Android-demo.apk`（只有假数据，还不能登录真实邮箱）。
2. ✅ Kotlin 引擎（2026-10-25，v0.4.0）：`android/app/src/main/java/com/moyer/mail/engine/`
   - JavaMail 安卓版（`com.sun.mail:android-mail:1.6.8`）收信；授权码用 Android Keystore 加密；SQLite 存信头和正文缓存。
   - 已完成：添加/编辑/删除账号（含连接测试、163 的 ID 命令）、文件夹列表、增量同步、IDLE 实时推送（应用打开时）、读信（GBK 等编码、内嵌图片）、已读/星标、删除/归档/移动、全部标为已读、联系人补全、翻译（Google / 微软 Azure / 大模型 / DeepL）。
   - 手机实测（adb reverse 连电脑上的测试服务器）：在手机上的添加账号界面里添加测试账号 → 同步 6 封 → 读信 → 新邮件约 0.5 秒推到手机 → 删除后服务器“已删除”里出现。
   - 注意：Google 免费翻译在手机网络上返回 429（被限流），手机上建议在 设置 → 翻译 换成大模型（DeepSeek 等）或微软翻译。
   - 调试工具：`scripts/android-eval.mjs` 可以在手机上运行中的 App 里执行 JS（需先 `adb forward tcp:9222 localabstract:webview_devtools_remote_<pid>`）。
3. ✅ 发信、附件、通知、后台收信（2026-10-25，v0.5.0）：
   - 发信（`Send.kt`）：回复 / 全部回复 / 转发（带上原邮件附件）、从手机选文件当附件（系统文件选择器，复制到应用缓存）、正文里粘贴的图片转成内嵌附件、存一份到“已发送”、回复后给原邮件打上“已回复”。附件一律 base64 编码（JavaMail 默认会把纯 ASCII 文件按 7bit 原样发，换行被改成 CRLF，文件就坏了——实测发现后修掉）。
   - 附件：点卡片 → 系统“用什么应用打开”（FileProvider）；“另存为” → 保存到 `下载/Moyer Mail`。安装包、exe 等不允许直接打开。
   - 系统通知（`Notifier.kt`）：新邮件显示发件人、主题、账号，多封合并成一条；点通知直接打开那封邮件。应用正开着时不弹；打开应用后自动收起。新邮件通知带分组摘要，否则安卓 16 会把它和常驻通知硬凑成一组、整组划不掉。
   - 后台收信（`MailService.kt`）：前台服务保持 IDLE 连接，通知栏有一条“正在接收邮件”（最低优先级）。设置 → 通用 →“退到后台后继续收信”可关；“允许在后台运行”按钮打开系统的电池优化对话框（要用户自己点允许）。
   - 手机实测：转发带 PDF 的邮件 → 测试服务器收到，“已发送”里的附件和原文件逐字节一致；另存为、打开附件、后台收到新邮件弹通知、点通知打开邮件都正常。
   - 安装包：`dist/MoyerMail-Android-0.5.0.apk`。
4. 还没做：收信规则、定时发送、稍后提醒、服务器搜索、加载更早的邮件、Outlook 登录（OAuth）。现在点这些会提示“手机版暂时还不支持…”。

**环境**（都已就绪）：
- JDK 21：`D:\AI\jdk-21.0.12.1+1`（Temurin，Gradle 8.14 不能用 Android Studio 自带的 JDK 25）
- Android SDK：`%LOCALAPPDATA%\Android\Sdk`（Android Studio 装的）
- 测试手机：一加 PLZ110，Android 17，USB 调试已开

**常用命令**：
```
npm run android:sync          # 构建界面并复制进 android/ 工程
npm run android:apk           # 再打包 debug APK（需要 JAVA_HOME 指向 JDK 21，ANDROID_HOME 指向 SDK）
adb install -r android/app/build/outputs/apk/debug/app-debug.apk
```
相关代码：`capacitor.config.ts`、`src/renderer/src/native.ts`（返回键、状态栏）、`styles.css` 末尾的 `.native` 样式、`scripts/make-icon.mjs`（同时生成安卓图标和启动画面）。

## 开发提示
- 测试时一定用 `MOYER_DATA_DIR` 指定别的数据目录，不要碰 `%APPDATA%\Moyer Mail`（真实账号数据）。
- 本地假邮件服务器：`node tests/fake-servers.mjs`（IMAP 1143 / SMTP 1025，testuser / testpass），里面有一组三封的会话、一封德语带附件邮件等。
- 截图调试：`MOYER_SCREENSHOT=xx.png MOYER_SCREENSHOT_JS="脚本" MOYER_SCREENSHOT_EXIT=1` 启动 Electron，会在页面里执行脚本后截图退出。
- 数据库结构有改动时，只能往 `src/core/db.ts` 的 `MIGRATIONS` 末尾追加新步骤，不要改已发布的步骤。设置项需要强制改默认值时，参考 `settings.ts` 里的 `settings_rev`。
