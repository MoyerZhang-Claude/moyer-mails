# 开发进度（下次从这里继续）

## v0.2.0（2026-10-23）

### 已完成、可以用
- **数据升级保护**：数据库带版本号，升级前自动备份为 `moyer-mail.db.bak-v旧版本号`。已用旧版数据验证：邮件、账号、密码都不丢。
- **全部标为已读**：列表顶部的 ✓✓ 按钮，服务器上没缓存的未读也一起处理。
- **列表标题翻译**：外语标题直接显示中文译文（带“译”字，鼠标停留看原文）。设置 → 翻译 里可以关。
- **服务器端搜索**：本地搜不到时，点“在服务器上搜索更早的邮件”（Gmail 搜“所有邮件”，其他邮箱搜收件箱/已发送/归档）。
- **稍后提醒**：右键邮件 → 稍后提醒…（或多选后点闹钟），邮件先从收件箱消失，到点重新变为未读并弹通知。侧栏“稍后处理”里能看到。

## 开发提示
- 测试时一定用 `MOYER_DATA_DIR` 指定别的数据目录，不要碰 `%APPDATA%\Moyer Mail`（真实账号数据）。
- 本地假邮件服务器：`node tests/fake-servers.mjs`（IMAP 1143 / SMTP 1025，testuser / testpass）。
- 数据库结构有改动时，只能往 `src/core/db.ts` 的 `MIGRATIONS` 末尾追加新步骤，不要改已发布的步骤。
